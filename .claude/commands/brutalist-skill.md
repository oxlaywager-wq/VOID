# BRUTALIST SKILL — Design Brutaliste Industrial

Grilles rigides, typographie massive, look terminal/raw.

## Principes brutalistes
- Polices : monospace, slab-serif, ou sans ultra-bold
- Couleurs : noir/blanc + 1 couleur vive en accent
- Borders épaisses et visibles
- Grid : strict, visible, parfois apparent
- Pas de border-radius (ou très peu, <4px)
- Textures : grain, noise, scanlines

## Signature visuelle
```css
/* Brutalisme typique */
font-family: 'Courier New', monospace;
border: 3px solid black;
box-shadow: 6px 6px 0 black;
background: #FFFF00; /* accent jaune ou rouge vif */
```

## Composants brutalistes
- Boutons : solides, avec offset shadow
- Cards : border épaisse, no radius, shadow offset
- Nav : horizontal, tous les items visibles, séparateurs
- Images : noir/blanc ou duotone
