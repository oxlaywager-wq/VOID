# IMAGES TASTE SKILL — Workflow Image-First

Génère une image de référence visuelle avant de coder. L'image guide toutes les décisions de design.

## Workflow

### Étape 1 : Brief visuel
Avant de coder, décrire en détail l'image de référence souhaitée :
- Palette de couleurs exacte (hex codes)
- Style général (photo, illustration, 3D render, flat)
- Ambiance (sombre/clair, dynamique/calme, luxe/tech)
- Éléments clés à inclure

### Étape 2 : Prompt image
Générer un prompt pour un outil de génération d'images :
```
[STYLE] [SUBJECT] [MOOD] [COLORS] [TECHNICAL]
Example: "Premium dark agency website hero, floating 3D geometric 
shapes in purple and violet, cinematic lighting, depth of field, 
8K render, Behance featured"
```

### Étape 3 : Code from image
Traduire fidèlement l'image en code :
- Extraire la palette exacte
- Reproduire les proportions et l'espacement
- Animer les éléments statiques
- Ajouter les micro-interactions manquantes dans l'image

## Références visuelles premium
- Dribbble "dark landing page 2024"
- Awwwards "site of the day" archives
- Behance "web design 2025"
- Linear.app, Vercel.com, Framer.com
