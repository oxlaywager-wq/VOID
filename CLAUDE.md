# VOID — Agence de Création de Sites Web

## Skills installés

Les skills suivants sont disponibles via `/skill-name` dans Claude Code :

| Commande | Description |
|---|---|
| `/taste-skill` | Skill principal — design frontend premium, asymétrique, anti-clichés IA |
| `/gpt-taste` | Variante stricte — framework Awwwards, AIDA, GSAP, bento grids |
| `/images-taste-skill` | Workflow image-first — génère une image de référence avant de coder |
| `/redesign-skill` | Refonte de projet existant — audit complet et améliorations ciblées |
| `/soft-skill` | Esthétique premium et soft — whitespace, motion fluide, double-bezel |
| `/minimalist-skill` | Minimalisme éditorial — style Notion/Linear, typographie raffinée |
| `/brutalist-skill` | Brutalisme industriel — grilles rigides, typographie massive, look terminal |
| `/stitch-skill` | Génère un DESIGN.md pour Google Stitch — règles sémantiques IA |
| `/output-skill` | Enforcement du code complet — zéro placeholder, zéro raccourci |

## Utilisation recommandée

Pour un nouveau site client :
1. `/taste-skill` ou `/soft-skill` pour un site moderne et premium
2. `/output-skill` en complément pour garantir un code 100% complet
3. `/redesign-skill` pour améliorer un site existant
