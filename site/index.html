Traitement automatique des emails fournisseurs → classement Excel OneDrive

Qu'est-ce que ce Zap fait concrètement ?

Chaque fois qu'un email d'un fournisseur arrive dans Gmail, le Zap lit l'email, visite automatiquement le site du fournisseur, analyse tout avec l'IA, puis ajoute une ou plusieurs lignes dans votre fichier Excel — sans que vous ayez à faire quoi que ce soit.

Les 8 étapes du Zap
1
Gmail

Détection de l'email

Zapier surveille votre boîte Gmail. Dès qu'un email contient des mots comme bag, packaging, sac, factory, manufacturer, supplier… dans l'objet, le Zap se déclenche.

2
Formatter by Zapier

Extraction de l'URL du site fournisseur

Zapier lit le texte de l'email et en extrait automatiquement l'adresse du site web du fournisseur (ex: www.example-bags.com).

3
Webhooks → Jina.ai

Lecture du site fournisseur

Zapier envoie l'URL à Jina.ai qui visite le site et renvoie son contenu en texte brut. C'est comme si Zapier lisait le site à votre place.

4
Gemini API via Webhooks

Analyse par l'IA

L'IA reçoit l'email + le contenu du site et produit une fiche structurée : nom, pays, familles de produits, certifications, score qualité… en JSON.

5
Formatter by Zapier

Extraction du JSON

Zapier prend la réponse textuelle de l'IA et identifie le JSON à l'intérieur pour pouvoir utiliser chaque champ séparément.

6
Code by Zapier

Nettoyage des données

Un petit programme JavaScript corrige automatiquement les bugs : convertit VRAI/FAUX en Oui/Non, et découpe la liste des familles pour que le Looping puisse les traiter une par une.

7
Looping by Zapier

Boucle sur chaque famille de produit

Si un fournisseur propose 3 familles (ex: Sac coton, Sac Luxe, Doypack), le Looping va répéter l'étape suivante 3 fois — une ligne Excel par famille.

8
Microsoft Excel — OneDrive

Ajout dans le tableau fournisseurs

Zapier ajoute une ligne dans Tableur Fournisseurs tests.xlsm, onglet Feuil1, avec toutes les colonnes remplies automatiquement.

!
Les 4 problèmes et leurs corrections
🔤

Problème 1 — VRAI/FAUX au lieu de Oui/Non

L'IA retournait true/false (anglais) que Zapier traduisait en VRAI/FAUX en français
✓ Correction

Le prompt oblige l'IA à écrire uniquement les mots "Oui", "Non" ou "Non mentionné" — jamais des booléens. Et le Code by Zapier (Step 6) vérifie et corrige en double sécurité.

📋

Problème 2 — familles_list en JSON brut dans Excel

La cellule Excel recevait [{"famille":"Sac coton",...}] tel quel au lieu des vraies valeurs
✓ Correction

Le Code by Zapier parse (décode) le tableau JSON et exporte 3 colonnes séparées : famille, sous_type et commentaire_produit — prêtes pour Excel.

🔁

Problème 3 — Looping ne crée qu'une seule ligne

familles_list était une chaîne de texte non parsée → Looping voyait 1 seul élément
✓ Correction

Le Code by Zapier crée des line items (éléments de liste) avec le séparateur ,,, que Looping reconnaît. Si 3 familles → 3 lignes Excel automatiquement.

⚠️

Problème 4 — Gemini "Unknown name raw"

Le webhook envoyait {"raw":"..."} — un champ que l'API Gemini ne reconnaît pas
✓ Correction

L'API Gemini attend un format précis : {"contents":[{"parts":[{"text":"..."}]}]}. Voir la configuration complète ci-dessous.

</>

Code by Zapier (Step 6)

Avant de coller ce code, configurez ces Input Fields dans Zapier :

  • raw_json → pointez sur {{step5.output}}
  • familles_raw → pointez sur {{step5.familles_list}}
Code by Zapier — Parse + Normalise JavaScript 
// Récupère le JSON brut de l'IA
const rawJson = inputData.raw_json || "";

// Nettoie les ```json que l'IA ajoute parfois
const cleaned = rawJson
  .replace(/^```json\s*/i, "")
  .replace(/^```\s*/i, "")
  .replace(/```\s*$/i, "")
  .trim();

let data = JSON.parse(cleaned);

// Convertit true/false/VRAI/FAUX → Oui/Non
function normalizeOuiNon(val) {
  if (!val) return "Non mentionné";
  const s = String(val).toLowerCase().trim();
  if (["oui", "yes", "true", "vrai"].includes(s)) return "Oui";
  if (["non", "no", "false", "faux"].includes(s)) return "Non";
  return "Non mentionné";
}

["fsc", "pefc", "ecovadis", "gots", "oeko_tex"].forEach(f => {
  data[f] = normalizeOuiNon(data[f]);
});

// Parse la liste des familles
let familles = Array.isArray(data.familles_list)
  ? data.familles_list
  : JSON.parse(data.familles_list || "[]");

if (!familles.length) familles = [{ famille: "Autres", sous_type: "", commentaire_produit: "" }];

// Prépare les line items pour le Looping (séparateur ,,,)
output = {
  fournisseur:          data.fournisseur || "",
  statut:               data.statut || "Inactif",
  contact_prenom_nom:   data.contact_prenom_nom || "",
  email:                data.email || "",
  site_web:             data.site_web || "",
  pays:                 data.pays || "",
  continent:            data.continent || "",
  conditions_livraison: data.conditions_livraison || "Non mentionné",
  port_depart:          data.port_depart || "",
  fsc:                  data.fsc,
  pefc:                 data.pefc,
  ecovadis:             data.ecovadis,
  gots:                 data.gots,
  oeko_tex:             data.oeko_tex,
  score_total:          String(data.score_total || ""),
  score_detail:         data.score_detail || "",
  resume:               data.resume || "",
  visite:               data.visite || "Non",
  familles_count:       String(familles.length),
  familles_famille:     familles.map(f => f.famille).join(","),
  familles_sous_type:   familles.map(f => f.sous_type).join(","),
  familles_commentaire: familles.map(f => f.commentaire_produit).join(","),
};
